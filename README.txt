FLOWMAX - VS CODE PROJECT

Included:
- index.html: user interface
- style.css: styling
- script.js: graph interactions and max-flow algorithm

Run:
1. Extract this ZIP.
2. Open the FlowMax_VSCode folder in VS Code.
3. Install the Live Server extension.
4. Right-click index.html and choose "Open with Live Server".

This is a browser-only HTML/CSS/JavaScript project. No database or backend is required.
